# Yêu Dạy Học — plugin cho Claude

Soạn câu hỏi, soạn đề theo ma trận vào ngân hàng Yêu Dạy Học. Kết nối tới: app.yeudayhoc.vn.

## Cài
claude.ai → Customize → Plugins → Add → Add marketplace → Add from a repository → dán địa chỉ kho này → cài plugin
`yeu-day-hoc` → mở plugin → Connectors → Connect → đăng nhập Yêu Dạy Học → Cho phép.

Phiên bản 1.3.7. Kho này được sinh tự động từ mã nguồn Yêu Dạy Học — đừng sửa tay.
